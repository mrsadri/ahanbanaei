# سایت آهن‌آلات بنایی

راهنمای این پروژه به فارسی. جزئیات فنی کامل در `BUILD-PLAN.md` است؛ این فایل
فقط کارهای روزمره را توضیح می‌دهد.

## اجرای سایت روی سیستم خودتان (برای تست)

۱. Node.js نسخه ۲۰ نصب باشد.
۲. در پوشه پروژه:

```
npm install
npm run dev
```

۳. آدرسی که در ترمینال نمایش داده می‌شود (معمولاً `http://localhost:5173`) را
   در مرورگر باز کنید. هر تغییری در فایل‌ها را ذخیره کنید، صفحه خودش
   به‌روز می‌شود.

## چطور یک شماره تلفن را تغییر دهیم؟

فایل `src/data/content.json` را باز کنید. بخش `contact.phones` را پیدا کنید:

```json
"phones": [
  { "id": "shop", "labelFa": "فروشگاه", "display": "۰۲۱-۵۵۱۲۳۴۵۶", "tel": "+982155123456" },
  ...
]
```

- `display` همان چیزی است که روی سایت نمایش داده می‌شود (با اعداد فارسی).
- `tel` همان شماره است اما با فرمت بین‌المللی و اعداد انگلیسی، برای اینکه
  دکمه تماس درست کار کند (مثال: `+98912...`).

همین‌طور شماره واتس‌اپ در `contact.whatsapp.number` (بدون `+`، فقط عدد).

بعد از ذخیره فایل، تغییر را کامیت و پوش کنید؛ ظرف چند دقیقه سایت زنده
به‌روز می‌شود.

## چطور یک محصول جدید اضافه کنیم؟

دو فایل باید تغییر کند:

۱. **`src/data/products.json`** — اگر محصول از یک دسته موجود است (مثلاً
   میلگرد، تیرآهن)، فقط یک آیتم جدید به آرایه `items` اضافه کنید. اگر دسته
   کاملاً جدید است، یک آیتم به `categories` هم اضافه کنید.

۲. هر محصول یک شناسه یکتا (SKU) دارد به شکل `نوع_سایز_گرید`، مثلاً
   `rebar_14_a3` یعنی میلگرد، سایز ۱۴، گرید A3. این شناسه باید در سه فایل
   یکسان باشد: `products.json`، `prices.shop.json` و فایل قیمت بازار
   (که خودکار نوشته می‌شود). اگر شناسه را اشتباه تایپ کنید، قیمت آن محصول
   روی سایت نمایش داده نمی‌شود.

نمونه یک آیتم:

```json
{
  "sku": "rebar_28_a3",
  "categoryId": "rebar",
  "type": "rebar",
  "typeFa": "میلگرد آجدار",
  "size": "28",
  "sizeFa": "۲۸",
  "grade": "a3",
  "gradeFa": "A3",
  "standardFa": "INSO 3132",
  "unit": "kg",
  "unitFa": "کیلوگرم",
  "lengthM": 12,
  "factoryFa": "ذوب‌آهن اصفهان",
  "featured": false
}
```

## چطور قیمت‌های فروشگاه خودمان را به‌روز کنیم؟

این تنها بخشی از سایت است که **هر روز** باید دستی به‌روزرسانی شود.

۱. فایل `src/data/prices.shop.json` را باز کنید.
۲. برای هر کالا، عدد `price` را تغییر دهید (تومان، بدون کاما، عدد صحیح).
   اگر کالایی موجود نیست، `inStock` را روی `false` بگذارید.
۳. حتماً خط `updatedAt` بالای فایل را هم به تاریخ و ساعت همان لحظه تغییر
   دهید (فرمت: `2026-08-16T09:00:00+03:30`).
۴. فایل را ذخیره، کامیت و پوش کنید.

با هر پوش، سایت خودش دوباره ساخته و منتشر می‌شود (چند دقیقه طول می‌کشد).
این فایل را **هیچ ربات یا اسکریپتی دست نمی‌زند** — فقط شما آن را ویرایش
می‌کنید.

⚠️ نکته مهم: مقادیر فعلی این فایل همه صفر (`0`) هستند، چون قیمت واقعی هنوز
وارد نشده. پیش از انتشار نهایی سایت، همه این قیمت‌ها را با عدد واقعی
جایگزین کنید.

## قیمت مرجع بازار از کجا می‌آید؟

فایل `src/data/prices.market.json` را **هرگز دستی ویرایش نکنید**. این فایل
هر روز صبح خودکار توسط یک اسکریپت از سایت‌های قیمت آهن به‌روزرسانی و
کامیت می‌شود. اگر یک منبع قطع یا خراب باشد، قیمت‌های قبلی همان منبع نگه
داشته می‌شوند و روی سایت با نشان "به‌روزرسانی نشده" مشخص می‌شوند؛ اگر خیلی
قدیمی شوند، به‌جای عدد اشتباه، پیام "برای قیمت امروز تماس بگیرید" نمایش
داده می‌شود.

می‌خواهید همین الان یک بار اسکریپت را دستی اجرا کنید؟ در گیت‌هاب، تب
Actions، روی «Scrape market prices» کلیک کنید و «Run workflow» را بزنید.

## چطور عکس اضافه کنیم؟

عکس‌های خام (فایل‌های اصلی موبایل، بدون فشرده‌سازی) را در پوشه‌های زیر
بگذارید (این پوشه در گیت ذخیره نمی‌شود، فقط محلی است):

```
raw-photos/hero/hero.jpg          → عکس اصلی صفحه اول
raw-photos/gallery/g01.jpg ...    → عکس‌های گالری
raw-photos/products/rebar.jpg ... → عکس هر دسته محصول
```

بعد این دستور را اجرا کنید:

```
npm run images
```

عکس‌ها خودکار در چند اندازه و فرمت بهینه در `public/img/` ساخته می‌شوند.
راهنمای کامل تعداد و کیفیت عکس مورد نیاز در `BUILD-PLAN.md` بخش ۶.۵ است.

## اگر قیمت‌های سایت اشتباه به نظر رسید

۱. اول بخش «قیمت فروشگاه ما» را چک کنید — این قیمت‌ها را شما دستی وارد
   کرده‌اید، پس اگر اشتباه است باید در `prices.shop.json` اصلاح شود.
۲. بخش «مرجع بازار» قیمت خود شما نیست، فقط برای مقایسه است و منبع و زمان
   دریافت هر عدد کنارش نوشته شده.
۳. اگر یک بخش قیمت به‌جای عدد، پیام «برای قیمت امروز تماس بگیرید» نشان
   می‌دهد، یعنی داده به‌روز نیست — این یک اشکال نیست، دقیقاً همان رفتاری
   است که باید اتفاق بیفتد تا عدد اشتباه به مشتری نشان داده نشود.

## بررسی سریع قبل از انتشار

```
npm run check
```

این دستور همه مقادیر جای‌گذاری‌نشده (مثل `[[PHONE_SHOP_TEL]]`) را لیست
می‌کند. قبل از اینکه سایت را رسماً معرفی کنید، این لیست باید خالی باشد
(حداقل مواردی که در `BUILD-PLAN.md` بخش ۶ به‌عنوان «بلوکه‌کننده» علامت
خورده‌اند).
